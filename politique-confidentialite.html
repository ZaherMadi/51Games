Politique de confidentialité

1. Introduction

5Hcorporation, éditeur du site 51Games, s'engage à protéger la vie privée des utilisateurs de son site. Cette politique de confidentialité explique comment nous collectons, utilisons et protégeons vos données personnelles.

Date de dernière mise à jour : Janvier 2024

2. Données collectées

Nous collectons les types de données suivants :

  • Données de navigation : adresse IP, type de navigateur, pages visitées, durée de visite
  • Données de jeu : scores, pseudonymes (gamertags), statistiques de jeu
  • Cookies : préférences utilisateur, données de session

3. Utilisation des données

Vos données sont utilisées pour :

  • Améliorer votre expérience de jeu
  • Afficher les classements et scores
  • Analyser l'utilisation du site pour l'améliorer
  • Assurer la sécurité du site

4. Stockage local

Nous utilisons le stockage local (localStorage) de votre navigateur pour sauvegarder :

  • Vos scores de jeu
  • Votre gamertag
  • Vos préférences de jeu

Ces données restent sur votre appareil et ne sont pas transmises à nos serveurs sans votre consentement explicite.

5. Cookies

Notre site utilise des cookies pour :

  • Mémoriser vos préférences
  • Analyser le trafic (analytics)
  • Améliorer la performance du site

Vous pouvez désactiver les cookies dans les paramètres de votre navigateur, mais cela pourrait affecter certaines fonctionnalités du site.

6. Partage des données

Nous ne vendons pas vos données personnelles. Vos données peuvent être partagées uniquement avec :

  • Nos prestataires techniques (hébergement, analytics)
  • Les autorités compétentes si la loi l'exige

7. Vos droits

Conformément au RGPD, vous disposez des droits suivants :

  • Droit d'accès : obtenir une copie de vos données
  • Droit de rectification : corriger vos données inexactes
  • Droit à l'effacement : demander la suppression de vos données
  • Droit à la portabilité : recevoir vos données dans un format structuré
  • Droit d'opposition : vous opposer au traitement de vos données

Pour exercer ces droits, contactez-nous à : privacy@51games.fr

8. Sécurité

Nous mettons en œuvre des mesures de sécurité appropriées pour protéger vos données contre tout accès non autorisé, modification, divulgation ou destruction.

9. Modifications

Nous pouvons mettre à jour cette politique de confidentialité. Toute modification sera publiée sur cette page avec une nouvelle date de mise à jour.

10. Contact

Pour toute question concernant cette politique de confidentialité :
